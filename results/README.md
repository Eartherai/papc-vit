# Results

Recorded metrics and logs from the paper's experiments. Everything in the paper
is derived from these files; regenerate the tables with `python analyze.py --tables`.

## Result JSON

| File | Session | Top-level keys |
|---|---|---|
| `papc_A_results.json` | A — main SOTA table | `sota` |
| `papc_B_results.json` | B — ablation + gate clamping | `ablation`, `clamp` |
| `papc_C_results.json` | C — CIFAR-100 + weight sweep | `cifar`, `sweep`, `scaling_law` |
| `papc_D_results.json` | D — 5-seed runs | `extended`, `learned_weights` |
| `papc_final_runs.json` | follow-up top-up runs | `clamp`, `sota`, `extended` |

### Schema

Runs are nested `results[section][dataset][condition] = [run, ...]`, one entry
per seed. Each run is:

```json
{
  "acc":   0.9919,        // top-1 accuracy
  "auc":   0.9974,        // macro one-vs-rest ROC-AUC
  "ece":   0.0182,        // 15-bin Expected Calibration Error
  "gate":  0.0072,        // mean |tanh(gate)| over PC layers (0 for vanilla)
  "lw":    [0.002, ...],  // learned per-layer weights (PAPC only; else null)
  "t_min": 38.5           // wall-clock minutes for the run
}
```

The weight sweep (`sweep`) stores condensed `{"auc": [...], "ece": [...]}` per
weight instead of full run dicts. `scaling_law` holds the fitted
`{k, alpha, r2, sizes, wopt}` for `w* = k * n^(-alpha)`.

## Logs

`logs/` holds two kinds of file:

| Pattern | What it is |
|---|---|
| `training_*.log` | **Captured console output** from the original A100 training runs — GPU banner, per-seed progress lines, per-dataset summaries, wall-clock totals. |
| `session_*.log` | **Exported metric tables** derived from the JSON above: one greppable line per run plus per-condition aggregates. Regenerated by `python analyze.py --logs`. |

The `training_*.log` files are the primary record — they are the actual stdout of
the runs that produced the JSON. For example, from `training_session_B.log`:

```
=== dermamnist (n=7007) ===
  vanilla        s0: AUC=0.9821 ACC=0.8778 ECE=0.0720 gate=0.000 (3.0m)
  fixed_0.05     s1: AUC=0.9569 ACC=0.3930 ECE=0.2385 gate=0.055 (9.8m)
  PAPC           s0: AUC=0.9811 ACC=0.8653 ECE=0.0886 gate=0.007 (9.7m)
```

and the scaling law being fitted live in `training_session_C.log`:

```
SCALING LAW: w* = 256.7 * n^(-1.412)  R2=0.831
```

Across all sessions: **269 runs, 36.2 GPU-hours** of recorded train and eval time.
